# **App Name**: SakuProduk

## Core Features:

- Pencarian Real-time Pintar: Kolom pencarian di bagian atas yang menyaring daftar produk secara instan saat pengguna mengetik tanpa jeda.
- Katalog Harga Minimalis: Tampilan daftar yang hanya menampilkan nama produk dan harga jual untuk navigasi yang cepat dan bersih.
- Form Input Produk Offline: Formulir sederhana untuk memasukkan Nama Produk, Harga Beli, dan Harga Jual yang langsung disimpan ke penyimpanan lokal perangkat.
- Backup Ekspor CSV: Fitur satu klik untuk mengekspor seluruh basis data lokal ke dalam format file CSV untuk pencadangan.
- Restorasi Impor CSV: Mengunggah file CSV dari penyimpanan perangkat untuk mengisi kembali daftar produk secara otomatis tanpa duplikasi.
- Evaluator Margin (AI Tool): Asisten AI yang menggunakan logika penalaran sebagai tool untuk memberikan saran jika selisih harga beli dan harga jual terlalu tipis.
- Database Lokal Independen: Sistem penyimpanan data sepenuhnya offline di dalam aplikasi yang tidak memerlukan internet atau proses login.

## Style Guidelines:

- Primary color: Sapphire Blue (#2563EB) yang mencerminkan profesionalisme dan kepercayaan dalam pengelolaan data bisnis.
- Background color: Sky Tint (#F1F5F9) yang memberikan kesan bersih, ringan, dan meningkatkan keterbacaan teks.
- Accent color: Ocean Cyan (#0EA5E9) untuk membedakan elemen interaktif seperti tombol tambah dan ikon navigasi.
- Menggunakan font 'Inter' (Sans-serif) untuk tampilan yang modern, netral, dan sangat objektif, ideal untuk angka-angka harga dan tabel data.
- Ikon berbasis garis (line-based) yang tipis dan minimalis untuk menjaga aplikasi tetap ringan secara visual.
- Tata letak single-column yang memfokuskan pengguna pada daftar vertikal, dengan tombol aksi utama (FAB) yang mudah dijangkau oleh ibu jari.
- Transisi halus (fade-in) saat menyaring produk untuk memberikan umpan balik visual yang responsif.
